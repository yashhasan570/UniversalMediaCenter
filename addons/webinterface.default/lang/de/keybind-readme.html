Tastaturkürzel

Universal Media Center kann mit der Tastatur bedient werden, unten wird die Standardbelegung beschrieben. Die Tastaturbelegung kann in Einstellungsseite geändert werden, verfügbar sind:

Universal Media Center

Die Tastaturbedienung von Universal Media Center ist wegen der Standardfunktionen des Browsers zunächst deaktiviert (z.B. werden Pfeil hoch / Pfeil runter zum Scrollen benutzt). [Browser Befehl] = [Universal Media Center Aktion].

Pfeil LINKS = Richtung LINKS
Pfeil RECHTS = Richtung RECHTS
Pfeil HOCH = Richtung HOCH
Pfeil RUNTER = Richtung RUNTER
RÜCKSCHRITT = Zurück
ENTER = Auswählen
TAB = Schließen
LEERTASTE = Abspielen/Pause
Taste "C" = Kontextmenü
Taste "+" = Lauter
Taste "-" = Leiser
Taste "M" = Stummschalten
Taste "X" = Stopp
Taste "T" = Untertitel umschalten
Taste ">" = Nächster
Taste "<" = Vorheriger
Taste "\" = Vollbild
Taste "O" = Bildschirmanzeige

Verbesserungsverschläge? Klicke hier.

Browser

Mit der Tastatur wird erstmal nur der Browser gesteuert. Wenn die Fernbedienung geöffnet ist, steuern die Tasten jedoch nur Universal Media Center.

Beides

Tastaturbefehle werden in Universal Media Center und im Browser ausgeführt. Wenn die Fernbedienung geöffnet ist, wird nur Universal Media Center gesteuert. HINWEIS: Viele Tasten sind sowohl im Browser als auch in Universal Media Center belegt, z.B. Rückschritt/Löschen.
