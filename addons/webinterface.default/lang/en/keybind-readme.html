Key Binds

You can use your keyboard to control Universal Media Center, this is the default setting but you can change what the keyboard controls on the settings page. The available options are:

Universal Media Center

The keyboard controls Universal Media Center and default keyboard interaction with the browser is disabled. (eg. using up and down arrows to scroll a page). [Browser command] = [Universal Media Center action].

Cursor LEFT = Direction LEFT
Cursor RIGHT = Direction RIGHT
Cursor UP = Direction UP
Cursor DOWN = Direction DOWN
BACKSPACE = Back
ENTER = Select
TAB = Close
SPACE BAR = Play/Pause
Key "C" = Context menu
Key "+" = Volume Up
Key "-" = Volume Down
Key "M" = Mute
Key "X" = Stop
Key "T" = Toggle subtitles
Key ">" = Play Next
Key "<" = Play Prev
Key "\" = Full screen
Key "O" = On-Screen Display

Browser

The keyboard controls the browser only. When the remote is open the keys will control only Universal Media Center.

Both

Keyboard commands are executed in Universal Media Center and in the browser. When the remote is open the keys will control only Universal Media Center. NOTE: Many commands are shared by both the browser and Universal Media Center. Eg. Backspace.
