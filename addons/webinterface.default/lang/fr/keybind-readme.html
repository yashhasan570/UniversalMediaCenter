Raccourcis clavier

Vous pouvez utiliser le clavier pour contrôler Universal Media Center. C'est le réglage par default mais vous pouvez changer ce comportement sur la page de paramètres. Les options disponibles sont:

Universal Media Center

Le clavier contrôle Universal Media Center et les interactions par défaut avec le navigateur sont désactivées (par ex utiliser flèche haut / bas pour défiler une page). [Commande du navigateur] = [Action Universal Media Center].

Flèche GAUCHE = Direction GAUCHE
Flèche DROITE = Direction RIGHT
Flèche HAUT = Direction HAUT
Flèche BAS = Direction BAS
BACKSPACE = Retour en arrière
ENTER = Sélectionner
TAB = Fermer
BARRE ESPACE = Jouer/Pause
Touche "C" = Menu contextuel
Touche "+" = Agumenter le volume
Touche "-" = Baisser le volume
Touche "M" = Couper le son
Touche "X" = Arrêter
Touche "T" = Activer/désactiver les sous-titres
Touche ">" = Jouer le prochain
Touche "<" = Jouer le précédent
Touche "\" = Plein écran
Touche "O" = Affichage sur écran (OSD)

Navigateur

Le clavier contrôle uniquement le navigateur. Si la télécommande est ouverte les touches ne contrôlent que Universal Media Center.

Les deux

Les commandes clavier sont exécutées dans Universal Media Center et dans le navigateur. Si la télécommande est ouverte les touches ne contrôlent que Universal Media Center. NOTE: Beaucoup de commandes sont partagées par le navigateur et Universal Media Center (par ex Backspace).
